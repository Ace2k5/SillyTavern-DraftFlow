DraftFlow
The reply is generated normally first, so you will see the draft and then the revised text replaces it in place. The chat keeps one message. The review first audits the active preset's requirements in an <audit> block, then rewrites the reply inside <revised>. Each refinement costs one extra generation call; use the toggle above to turn it off. Revert only restores the most recent refinement while that message still holds the revised text.

Details show the audit, the raw output, the prompt and the final reply, plus the model's reasoning when the backend returns it inline. Reasoning that arrives in a separate API field is discarded by quiet generation, so it cannot be shown here.
Review prompt
%DRAFT% is replaced with the reply being reviewed. SillyTavern macros such as {{char}} and {{user}} are resolved by the normal generation pipeline. Keep the <audit> then <revised> structure: the audit makes the model enumerate the preset's rules first, and the revised block is what replaces the reply.
