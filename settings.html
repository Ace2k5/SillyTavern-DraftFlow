DraftFlow
DraftFlow continues from the current chat. Send your own reply first, then run it from the wand menu, the button above, or /draftflow turns=3. Each run costs two generation calls (draft + review). Messages are inserted immediately; Undo only works while the batch is still at the end of the chat.
Prompt templates
%TURNS% is replaced with the batch size and %DRAFT% with the draft text. SillyTavern macros such as {{char}} and {{user}} are resolved by the normal generation pipeline. Keep the @@TURN@@ separator instruction intact or the batch will arrive as a single message.
