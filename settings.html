DraftFlow
The reply is generated normally first, so you will see the draft and then the revised text replaces it in place. The chat keeps one message. Each refinement costs one extra generation call; use the toggle above to turn it off. Revert only restores the most recent refinement while that message still holds the revised text.
Review prompt
%DRAFT% is replaced with the reply being reviewed. SillyTavern macros such as {{char}} and {{user}} are resolved by the normal generation pipeline. Keep the <revised> instruction intact so the extension can tell the rewrite apart from any stray commentary.
